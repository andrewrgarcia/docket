# resume contract — moved

This contract is now the **Salvation spec**: `SPEC.md` in the salvation repo
(`~/salvation`). It moved on 2026-10-03 so
the protocol is versioned apart from any one tool.

docket is its reference implementation: `dk resume` implements Salvation spec
v1 (D1–D5) — sessions in `<book>/sessions/` as a fur archive, found by the tag
`dk-<card id>`, the code index from `WHITE.md`, and `RESUME.md` ordered card →
sessions → code. Where docket's behaviour and the spec disagree, the spec wins
and docket has a bug.
